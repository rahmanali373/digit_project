# Handwritten Digit Prediction

## Project Description
This project predicts handwritten digits (0-9) using CNN and Vision Transformer (ViT).

## Models
- CNN
- Vision Transformer

## Results
- CNN Accuracy: 91.85%
- ViT Accuracy: 84.07%

## Requirements
- Python
- PyTorch
- Streamlit
- NumPy
- Pillow
- Scikit-learn

## Run Application
python -m streamlit run app.py
